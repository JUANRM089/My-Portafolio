Projects

SJStock — Sistema de gestión de inventario

  • Sistema web para gestión de inventario desarrollado con JavaScript y Supabase/PostgreSQL como motor de base de datos. Es tu proyecto insignia, que ha abarcado varios semestres: incluye diseño de arquitectura, elaboración de un manual de modificaciones en LaTeX, y preparación de una sustentación técnica sobre base de datos, Supabase, APIs REST y consultas SQL.

Editor de imágenes con Python y álgebra lineal

  • Editor de imágenes desarrollado en Python que representa cada imagen como una matriz (con NumPy) y aplica conceptos de álgebra lineal —transformaciones matriciales y operaciones con vectores— para realizar filtros y ajustes sobre la imagen, como transformaciones geométricas (rotación, escalado) y manipulación de color y píxeles.

Labyrinth Duel

  • Videojuego arcade PvP en 2D desarrollado con Pygame, multijugador local para PC. Dos jugadores se enfrentan en un laberinto, disparándose hasta que uno alcance 7 puntos; cada ronda se reinicia y gana quien primero llegue a 7 victorias.
